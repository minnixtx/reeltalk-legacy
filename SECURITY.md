# Security Policy

## Reporting a Vulnerability

Please report security issues using the [Security tab of the ReelTalk
repository](https://github.com/minnixtx/reeltalk/security/advisories/new).

ReelTalk is a fork of [BookWyrm](https://github.com/bookwyrm-social/bookwyrm);
vulnerabilities in shared upstream code may also be reported to the upstream
maintainer (`mousereeve@riseup.net`).
