# Contributing to ReelTalk

We'd love you to contribute to ReelTalk!

ReelTalk is a fork of [BookWyrm](https://github.com/bookwyrm-social/bookwyrm), so
the upstream contribution guide still describes how this codebase works:

- [How to Contribute (upstream BookWyrm docs)](https://docs.joinbookwyrm.com/contributing.html)

ReelTalk-specific plans and decisions are tracked in the
[GitHub repository](https://github.com/minnixtx/reeltalk).
